# HRS Sambandsøving

Treningsverktøy der Claude spiller Hovedredningssentralen (HRS) over samband for besetninger i 330 skvadron. ØVING: alle personer og data i scenariene er fiktive.

- **Åpne:** https://hilstan-web.github.io/hrs-bot/ (Safari på iPhone/iPad, eller Edge/Chrome på PC)
- **Oppsett:** se [OPPSETT.md](OPPSETT.md)
- **Scenarier:** [scenarier/](scenarier/) (case 1 og 2, innenfor 100 NM fra Rygge)

Siden er én fil (`index.html`). Talegjenkjenning og stemme kommer fra nettleseren. Claude kalles direkte fra nettleseren med en API-nøkkel som hver bruker legger inn selv, og som bare lagres på den enheten.
